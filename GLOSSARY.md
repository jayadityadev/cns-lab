# Cryptography and Network Security (CNS)

The domain concepts and terminology governing the implementation and analysis of classical and modern cryptographic systems in this repository.

## Language

**Plaintext**:
The unencrypted, human-readable original message or data provided as input to an encryption algorithm.
_Avoid_: Cleartext, source text, raw text

**Ciphertext**:
The transformed, unintelligible output generated by enciphering a plaintext using an encryption key.
_Avoid_: Encrypted message, coded text

**Key**:
The secret parameter or numeric value controlling the specific transformation of plaintext into ciphertext and vice versa.
_Avoid_: Secret, password, shift factor

**Caesar Cipher**:
A classical monoalphabetic substitution cipher where each letter in the plaintext is shifted by a fixed integer number of positions down the alphabet.
_Avoid_: Shift cipher, Caesar shift, rotation cipher

**Monoalphabetic Substitution**:
A cipher in which each symbol of the plaintext alphabet is mapped to a single fixed symbol of the ciphertext alphabet for the duration of the encryption process.
_Avoid_: Single-alphabet cipher, simple substitution

**Keyspace**:
The finite set of all distinct, valid keys that can be used with a cryptographic algorithm.
_Avoid_: Key range, key possibilities

**Exhaustive Key Search**:
A cryptanalytic attack that attempts decryption with every possible key in the keyspace until the correct plaintext is discovered.
_Avoid_: Brute-force attack, brute-forcing

**Frequency Analysis**:
The study of the frequency of letters or groups of letters in a ciphertext to deduce the underlying plaintext or key based on known language statistics.
_Avoid_: Letter counting, statistical cryptanalysis

**Round-Trip Property**:
The correctness guarantee that applying decryption with a key to a ciphertext previously encrypted with that same key reproduces the exact original plaintext.
_Avoid_: Reversibility, invertibility

**Polyalphabetic Substitution**:
A cipher that uses multiple substitution alphabets sequentially to encipher plaintext symbols, flattening single-letter frequency distributions.
_Avoid_: Multi-alphabet cipher, complex substitution

**Vigenère Cipher**:
A polyalphabetic substitution cipher that uses a repeated keyword to select shift values from a square table of shifted alphabets (Tabula Recta).
_Avoid_: Vigenere table, keyword cipher

**Key Stream**:
The sequence of key symbols or shift offsets aligned against plaintext characters during encryption.
_Avoid_: Shift sequence, running key

**Tabula Recta**:
A square 26-by-26 grid of shifted alphabets used for polyalphabetic substitution.
_Avoid_: Vigenère square, cipher table

**Kasiski Examination**:
A cryptanalytic method that deduces the key length of a repeated-key polyalphabetic cipher by analyzing distances between repeated ciphertext sequences.
_Avoid_: Kasiski test, repetition analysis

**Index of Coincidence**:
A statistical measure of the probability that two randomly chosen letters from a text are identical, used to identify key length in polyalphabetic ciphers.
_Avoid_: Friedman test, coincidence count

**One-Time Pad (OTP)**:
An encryption algorithm that combines plaintext with a secret, uniformly random key of equal length via modular addition or XOR, used strictly once.
_Avoid_: Vernam cipher, OTP cipher

**Perfect Secrecy**:
The information-theoretic condition where observing the ciphertext provides zero statistical information about the plaintext: P(M=m | C=c) = P(M=m).
_Avoid_: Unbreakable encryption, absolute security

**CSPRNG**:
A pseudo-random number generator possessing statistical randomness and unpredictability properties satisfying cryptographic security standards.
_Avoid_: Random generator, pseudo-RNG

**Exclusive-OR (XOR)**:
A bitwise logic operation that outputs 1 if and only if its input bits differ, acting as its own mathematical inverse: (A ^ B) ^ B = A.
_Avoid_: XOR addition, modulo 2 addition

**Two-Time Pad Attack**:
A cryptanalytic vulnerability occurring when a one-time pad key is reused across two ciphertexts, exposing the XOR difference of the plaintexts: C1 ^ C2 = M1 ^ M2.
_Avoid_: Key reuse attack, pad reuse

**Digital Signature**:
A mathematical mechanism that binds an authentic entity to a message using asymmetric cryptography, providing message integrity, authentication, and non-repudiation.
_Avoid_: Electronic signature, signed hash, cryptographic stamp

**RSA-PSS**:
An asymmetric digital signature standard combining RSA public-key math with the Probabilistic Signature Scheme padding (PKCS#1 v2.1) to achieve tight provable security.
_Avoid_: RSA signature, PKCS#1 padding, PSS cipher

**Message Digest**:
The fixed-size output produced by passing arbitrary data through a cryptographic hash function (e.g. SHA-256).
_Avoid_: Hash value, checksum, fingerprint

**Authenticity**:
The security property assuring the receiver that the message was created by the specific entity holding the corresponding private signing key.
_Avoid_: Veracity, validity, genuineness

**Integrity**:
The security property assuring that the message has not been altered, deleted, inserted, or modified in transit.
_Avoid_: Immutability, accuracy

**Non-Repudiation**:
The security property preventing a signer from successfully denying the authenticity of their signature or having sent the message, assuming the private key was not compromised.
_Avoid_: Irrefutability, legal binding

**Public Key Infrastructure (PKI)**:
The framework of hardware, software, policies, and Certificate Authorities that binds public keys to verified real-world identities using digital certificates.
_Avoid_: Key infrastructure, certificate authority system
